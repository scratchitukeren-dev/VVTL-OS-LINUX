# 🐧 VVTL - Very Very Tiny Linux 🚀
VVTL is a series of **super-minimalist** shell-based OS. ⚡ Developed by scratchitukeren-dev.
# 📊 Choose Your Version
I offer **three version** of minimalism to suit your needs:  
🥉 [Tiny]	**Normal** version of VVTL. Its only 329 bytes!  
🥈 [VeryTiny]	**Medium** version of VVTL. Its only 301 bytes!  
🥇 [VeryVeryTiny] This is the **smallest** version! Its only 204 bytes!🏆  
## 📝 Filename
[Tiny] = vvtl-tiny.sh  
[VeryTiny] = vvtl-verytiny.sh  
[VeryVeryTiny] = vvtl-vvtiny.sh
[!FUN FACT]
All versions are smaller than the legendary bootOS (512 bytes)!
⌨️ VVTL Commands (Varies by Version)
Type h to see what you can do:
h / v : 📖 Help & Version Info
p / r : 📂 Path (pwd) & Read (ls)
t : 📝 Make txt file
d : 🧹 Clear Terminal
x : 🚪 Exit OS
🚀 How to Run?
🐧 On Linux / Android (Termux/TermOne):
📥 Download the .sh file of your chosen version.
💻 Open your terminal (Recommended: TermOne Plus with hacker green text 🟢).
📂 Navigate to the directory: cd [path_to_file]
⚡ Run the OS:
bash
sh [file_name].sh
Use code with caution.
